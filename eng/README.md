# Английская версия SAFEBOX

Адрес при размещении репозитория в корне сайта: `/eng/`.
Точка входа: `index.html`. Все 15 страниц создаются из `../site/english.py` при запуске `../site/build.py`.

Общие изображения и стили находятся в `../site/assets/`. Английские интерактивные формы используют `english.js`; отдельный ключ localStorage не изменяет русский план подготовки.

RU / EN переключает между соответствующими страницами. HTML-тексты, подписи форм и скачиваемые документы локализованы. Исходные изображения и слайд презентации сохраняют русские надписи; они отмечены как оригинальные концепты.

Для просмотра по HTTP сервер должен запускаться из корня репозитория, а не из `site/`, чтобы одновременно обслуживать `/site/` и `/eng/`. Страницы также открываются как локальные HTML-файлы.

Оплата, отправка заявок, аптечный заказ и настоящий ИИ не подключены. Формы создают локальные черновики; сайт сообщает об этом до действия.
